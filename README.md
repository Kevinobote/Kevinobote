# Kevin Omondi Obote

Machine Learning Engineer and AI Researcher building NLP infrastructure for low-resource African languages: stopword corpora, morphological analysers, and evaluation benchmarks for Kiswahili and other Bantu languages, plus low-resource speech recognition (ASR).

- 💼 Founder & Lead Machine Learning Engineer at [Guild Code](https://kevin.guild-code.com); Cofounder & CTO at [Msingi AI](https://www.msingiai.com/)
- 🌍 Dataset Evaluation Lead at [KenyaNLP](https://github.com/Kevinobote/kenyanlp-website), a research community
- 📄 Established the first documented ASR baseline for Kalenjin (accepted, IEEE Xplore, AAIAC 2026)
- 🔗 Portfolio: [kevin.guild-code.com](https://kevin.guild-code.com/)
- 📫 kevinobote49@gmail.com · [ORCID](https://orcid.org/0009-0000-7099-2154) · [LinkedIn](https://linkedin.com/in/kevinobote)

## 🔬 Featured Research

| Project | What it is |
|---|---|
| [**Kalenjin-ASR**](https://github.com/Kevinobote/Kalenjin-ASR) | First documented ASR baseline for Kalenjin: two-stage Wav2Vec2-XLS-R fine-tuning + KenLM. CER 20.1%, about half the CER of the best model on PazaBench. AAIAC 2026 · [🤗 model](https://huggingface.co/RareElf/kalenjin-asr) |
| [**Kiswahili-Kitukuzwe**](https://github.com/Kevinobote/Kiswahili-Kitukuzwe) | End-to-end Kiswahili audio pipeline (ASR → sentiment → summarisation) served with FastAPI; code for my [MSc dissertation](https://github.com/Kevinobote/Kevin_MSc_Dissertation) |
| [**swahili-stopwords-nltk**](https://github.com/Kevinobote/swahili-stopwords-nltk) | Swahili stopword corpus for NLTK, built from frequency, Zipf and TF-IDF analysis plus morphology rules |
| [**naira-currency-benchmark**](https://github.com/Kevinobote/naira-currency-benchmark) | Naira banknote classification benchmark with a duplicate audit, 5-fold CV, calibration and a data-leakage experiment |
| [**From-Predictive-to-Generative-AI**](https://github.com/Kevinobote/From-Predictive-to-Generative-AI) | Hands-on workshop presented at UbuCon Africa 2026 |
